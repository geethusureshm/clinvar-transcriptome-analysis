# Transcriptome Analysis (ClinVar Integration)

## Overview
This project performs RNA-seq analysis including:
- PCA visualization
- Differential gene expression (limma)
- Volcano plot
- Functional enrichment (g:Profiler, Metascape)
- Candidate gene identification

## Key Results
- Identified top candidate genes related to immune response
- Integrated pathway and functional annotations

## Tools Used
- R (limma, ggplot2)
- g:Profiler
- Metascape
